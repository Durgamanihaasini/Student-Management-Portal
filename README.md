
# Student Activity Management Portal

## Lab Experiment 1
Semantic, Accessible HTML & the Browser Model (M1)

## Project Description
The Student Activity Management Portal is a webpage
developed for university students to explore upcoming
events, university activities and register for events.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Git and GitHub

## Features
- Semantic HTML webpage structure
- Upcoming university events
- University activities section
- Student registration form
- Accessible form fields
- Keyboard navigation support
- Registration confirmation message

## HTML Elements Used
- Header
- Navigation
- Main
- Section
- Article
- Aside
- Footer
- Forms and input elements

## Accessibility
The webpage follows basic accessibility practices,
including proper labels, heading hierarchy,
keyboard accessibility and browser validation.

Accessibility testing was performed using
Google Lighthouse / WAVE.

## Project Files
- index.html – Main webpage
- style.css – Webpage styling
- accessibility-report.txt – Accessibility audit report
- README.md – Project documentation

## How to Run
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
4. View the webpage in your browser.
